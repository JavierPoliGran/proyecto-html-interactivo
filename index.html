Lección 1: Anatomía y Fundamentos de HTML

HTML (HyperText Markup Language o Lenguaje de Marcado de Hipertexto) no es un lenguaje de programación tradicional, sino un lenguaje de marcado que le indica a los navegadores cómo estructurar y mostrar los elementos de una página web.

1. ¿Cómo se componen las etiquetas?

La gran mayoría de los elementos en HTML constan de una etiqueta de apertura, un contenido y una etiqueta de cierre:

  • <h1>Texto</h1>: Define un encabezado principal (título grande).
  • <p>Texto</p>: Define un párrafo de texto normal.
  • <strong>Texto</strong>: Aplica negrita y resalta texto importante.

2. Estructura esquelética de un documento HTML

Todo archivo HTML moderno debe contener una jerarquía estándar para que el navegador lo interprete correctamente:

<!DOCTYPE html> <!-- Define que es un documento HTML5 -->
<html lang="es">
  <head>
    <meta charset="UTF-8">
    <title>Título de la pestaña</title>
  </head>
  <body>
    <h1>¡Hola Mundo!</h1>
    <p>Este es mi primer párrafo en la web.</p>
  </body>
</html>
💡 Regla de oro: Nunca olvides cerrar tus etiquetas. Si abres un contenedor con <div>, asegúrate de cerrarlo más adelante con </div> para evitar que el diseño de tu página web colapse.
